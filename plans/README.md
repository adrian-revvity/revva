## Findings considered and rejected

- Sequential `git`/`gh` probes in `ship.checks()` — only runs while the Ship
  dialog is open; parallelizing is invisible to the user. Not worth doing.
- `chatManager.messages()` refetching up to 200 messages on invalidate —
  acceptable payload at current scale; revisit only if transcripts grow huge.
- SQLite lookups in `toSummary()` (N+1-ish ticket lookups) and
  `scriptManager.status()` — in-process better-sqlite3, sub-millisecond; noise.
- Missing lint config / near-zero tests — deliberate per AGENTS.md ("YOLO
  policy"); out of scope for any plan.
- Renderer bundle code-splitting — single-window Electron app; no benefit.
- `inbox.resync()` per-session serial calls kept as "investigate"-level until
  re-read: confirmed real, became plan 006.
- Migrating the 13 radix-based vendored ui files to base-ui — real inconsistency
  (components.json style is `base-nova`), but it's a design-system decision for
  the owner, not an obvious fix; explicitly deferred (noted in plan 008).
